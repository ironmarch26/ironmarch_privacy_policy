AdMob은 광고 제공, 광고 성과 측정 및 광고 사기 방지 등을 위해 관련 정보를 처리할 수 있습니다.

Google의 데이터 처리 방식에 대한 자세한 내용은 Google의 개인정보처리방침 및 AdMob 관련 안내를 참고하시기 바랍니다.
